 browser-based calculator for estimating file sizes of film scanning workflows using DPX and Apple ProRes formats.

Features

Film length conversion between meters and feet.

Automatic frame count calculation based on film format and perforation.

Editable frame count with automatic synchronization.

DPX file size estimation based on resolution, bit depth, channels, and frame overhead.

ProRes file size estimation based on codec, frame rate, and resolution.

Estimated playback duration and ProRes size range (±10%).

Custom scanning resolution support.

How to Use

Open the HTML file in a modern web browser.

Select the film format and, for 35mm, the perforation.

Enter the film length in meters or feet, or enter the frame count directly.

Select the scanning resolution and DPX settings.

Choose the ProRes codec and playback frame rate to view estimated file sizes.

Notes

ProRes file sizes are estimates because ProRes uses variable bitrate encoding.

Results depend on the selected settings and the accuracy of the input data.

The calculator runs locally in the browser and does not require installation.
